      and service-role JWTs.

      pre-rollout one; it must be identical.

- the smoke screening fails;
- any `42501` or `permission denied` appears in production logs;
- an invite or referral request returns 500.

|---|---|---|
| 1 | `begin; drop table if exists public.role_profiles; commit;` | Drops the role-profile cache; profiles are built per request again. Nothing reopened |

`supabase migration repair <version> --status reverted --linked`.
